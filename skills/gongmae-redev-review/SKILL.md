# 공매·경매 빌라 재개발 진입 검토

**핵심**: 판정은 세 축이다 — ① 분양자격(보존등기일 vs 권리산정기준일) ② 인수(대항력 보증금이 낙찰가에 따라 달라짐) ③ 시세(구역 프리미엄이 낀 블록 시세 vs 감정가). 셋을 섞지 말고 각각 판정한 뒤 입찰가로 합친다.

## 1. 문서 읽기 (PDF)

| 문서 | 방법 |
|---|---|
| 등기부·공매재산명세서(인터넷 발급) | `pdftotext`는 **한글이 사라진다**(폰트 CID). Read 도구로 PDF를 직접 읽는다 |
| 감정평가서(스캔) | Read가 pdftoppm을 요구하며 실패 → PyMuPDF로 페이지 렌더 후 PNG를 Read: `python -c "import fitz;d=fitz.open(p);[pg.get_pixmap(dpi=100).save(f'out/{i:02d}.png') for i,pg in enumerate(d)]"` (`python -I`는 사용자 site-packages를 못 봐 fitz 없음) |

뽑을 것: 보존등기일·사용승인일, 대지권, 말소기준(가장 이른 압류·가압류·근저당), 임차인 전입·확정일자·임차권등기·대위자, 갑구의 **강제경매개시결정(사건번호)**, 명세서의 배분요구 표·법정기일, 감정서의 **제시외(발코니 판넬 확장 = 위반건축물 의심)**·비교사례(해제거래 섞임 여부).

## 2. 재개발 진입 판정

- **권리산정기준일**: 연번 단계면 아직 미고시. 정의는 자치구 연번 공고문의 고지사항에 있다(광진구 = **구→시 추천일**). 다른 구는 그 구 공고문을 찾아 확인하고, 못 찾으면 "미확인"으로 적는다. 판정은 "보존등기일 < 기준일이면 분양대상"이고, 미고시라도 이미 지어진 건물은 이후 기준일보다 반드시 앞선다.
- **쪼개기**: 처음부터 집합건물 신축(보존등기에 대지권) → 기준일 전이면 각 호 독립 분양. 단독·다가구→다세대 **전환**이면 조례 제한 별도. 주택 소유자는 면적 무관 분양대상.
- **일몰제**: 도정법 20조는 구역지정 후부터. 연번·후보지 단계의 실질 일몰 = **반대 25% 이상 실효**(연번 실효 사례 있음).
- **구역계 중복**: 같은 동네에 연번 구역이 여럿이면 겹치는 구역은 **양쪽 추천 제외**. `C:\Users\m9938\jaegaebal\redev_zones.db`(zones 테이블, `dong LIKE '%구의%'`)·`_workspace/yeonbeon/A_report.md`에서 인접 연번 구역을 찾아 확인 항목에 넣는다.
- **노후도**: 블록 실거래의 준공연도 분포로 신축 비중을 본다(신축 많으면 선정 리스크).
- **토허**: 후보지 선정 시 지정. 공매(체납처분)·경매 취득은 예외 가능성 높음, 단 **되팔 때 매수자 실거주 요건 → 출구 축소**.

## 3. 권리·인수 (공매)

- 대항력 = 전입 다음날 0시 < 말소기준. 배분요구 했으면 배분 순서는 체납처분비 → 당해세 → 확정일자 임차인 → 법정기일 늦은 조세. 국세기본법 35조⑦의 임차인 우선 특례는 상속·증여·종부세만 대상이라 **재산세(지방세 당해세)는 보수적으로 임차인 앞**에 둔다.
- **배분요구 안 한 대항력 임차인 = 보증금 전액 인수** → `bid_calc.py --no-claim`.
- **인수액은 낙찰가의 함수다**: `인수 = max(0, 보증금 − (낙찰가 − 선순위))`. 실질원가 바닥 = 선순위+보증금. "시세 − 보증금"처럼 고정 차감하지 말 것 — 바닥 이상 낙찰이면 인수 0.
- 보증보험이 대위변제하면 같은 채권이 **임차인 배분요구 + 보증보험 양수금**으로 두 번 신고된다(배분은 한 번).
- **공매엔 인도명령이 없다** → 점유자 거부 시 명도소송.
- 같은 물건 법원 경매 병행 시 **먼저 대금 납부한 쪽이 소유권**. 두 일정을 나란히 비교해 회차별 최저가가 더 낮은 쪽으로 들어가고(법원 서울 20%·공매 10% 체감), 공매 낙찰 시엔 잔금을 기한 전 최대한 빨리 낸다.

## 4. 법원 사건 진행 조회

`analyze_case.py`가 "검색 결과 없음"이면 사건 부존재가 아니라 **매각기일 2주 밖**이다. 기일과 무관한 경매사건검색으로:

```
python skills/gongmae-redev-review/scripts/court_case_search.py 서울동부지방법원 2025 52539 <out_dir>
```
사건내역(청구금액·배당요구종기·당사자)·기일내역·**문건/송달내역**을 저장한다. 기일내역이 비어도 송달내역의 "매각기일 및 매각결정기일통지서 발송"이 보이면 기일이 이미 지정된 것 → 경매계 전화로 일자·감정가 확인.

## 5. 시세

```
python skills/gongmae-redev-review/scripts/villa_block_comps.py fetch --lawd 11215 --umd 구의 -o raw.json
python skills/gongmae-redev-review/scripts/villa_block_comps.py stats raw.json --jibun 241-8 --area 27.36 --block 221,224,... --rent-from 202507
```
- 블록 = 구역 대표지번 주변 본번 묶음. 반기 추이로 **연번·후보지 전후 프리미엄 상승분**을 분리한다.
- 해제거래는 'O' 행과 **표시 없는 쌍둥이 행**이 함께 온다 → 둘 다 제거(스크립트 처리). 준공 2년 미만 거래(신축 분양)는 추이 제외.
- 가치 두 개: 현재가(블록 최근 반기 중앙 × 층 보정) / 하방(감정가 ≈ 프리미엄 소멸).

## 6. 입찰가

```
python skills/gongmae-redev-review/scripts/bid_calc.py --appraisal … --deposit … --senior … --value-now … --value-down …
```
회차별 예정가(최초의 10%씩 체감, 50%까지)·인수액·취득세 구간별(1.1/8.4/12.4%) 하방 손익분기·10%/5% 마진 상한을 낸다. 권장 = 하방 손익분기~10% 마진 사이에 드는 회차, 상한 = 5% 마진. 다주택 여부를 모르면 세 구간을 다 제시.

## 산출물

보고서는 결론표 → 물건 → 재개발 진입 → 권리 → 시세 → 입찰가 → 확인할 것(체크박스) → 출처 순. 재개발 물건은 jaegaebal `_workspace/<구>/gongmae_<관리번호>/`에 보고서·스크립트 사본·블록 CSV를 커밋(원자료 JSON 제외). 로컬에 미커밋 변경이 원격과 겹치면 worktree에서 cherry-pick 후 push.

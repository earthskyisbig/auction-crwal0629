# AI 오답노트 — 2026-08-19 교정 3건 (화성 반월동 311-70 / 2025타경1152 보상분석 중 발견)

토지보상 경매 분석(tojibosang 프로젝트)에서 law.go.kr 원문 대조로 확인된 AI 통설·기존 노트의 오류 3건.

## 1. 토지 단기보유 양도세율 ≠ 주택 세율

- **오답**: 단기보유 양도세율 "1년 미만 70% / 1~2년 60%"를 토지에도 적용.
- **정답**: 70/60%는 **주택·조합원입주권·분양권** 세율. **토지는 1년 미만 50% / 1~2년 40%** (소득세법 제104조①2·3호).
- **왜 위험한가**: 토지 경매 단기 출구 시나리오에서 세금을 20%p 과대계상 → 수익률 판정이 통째로 틀어짐.
- 02_세금/양도세_다주택자_비과세.md §3에 교정 반영 완료.

## 2. 농지 이행강제금 — 조문·요율 모두 구버전 통설이 틀림

- **오답**: "농지법 제62조, 토지가액의 20%".
- **정답**: 2021-08-17 개정으로 **제63조**로 이동, 요율은 **감정가·공시지가 중 높은 가액의 연 25%**, 상한 없이 처분명령 이행 시까지 매년 반복 부과.
- **추가**: 2026-08-28 시행 개정으로 제11조① 처분명령이 "명할 수 있다" → **"명하여야 한다"(기속행위)**로 강화. 같은 개정에서 제10조① 단서 신설 — 토지거래허가구역 내 농지는 처분의무 1년 유예 배제.
- **맥락**: 시행령 제9조의 처분의무 면제 사유에 "수용 예정"은 없다(법제처 10-0186 — 전용협의 완료 농지도 실제 전용 전까지 처분의무 대상). "수용 기다리며 자경 안 함" 전략은 이행강제금 반복 부과에 정면 노출.

## 3. "농취증 미제출 보증금 몰수 = 재판예규 제943호" 통설은 원문에 없음

- **오답**: 재판예규 제943호(재민 97-1)가 농지취득자격증명 미제출 시 보증금 미반환을 규정한다는 통설 인용.
- **정답**: 재민 97-1 3개 판본 전부에 해당 문구 **부재**. 몰취의 실제 근거는 **재판예규 제1853호 제46조①3호**(매각불허가 시 보증금 반환 제외 사유) + **개별 사건의 특별매각조건**(매각물건명세서 기재). 따라서 물건별로 명세서의 특별매각조건 기재를 직접 확인해야 한다.
- **관련 판례**: 대법원 2014마62 — 농취증 반려가 행정적으로 부당해 행정소송에서 취소될 것이 예상되더라도 기한 내 미제출이면 매각불허가는 적법.
